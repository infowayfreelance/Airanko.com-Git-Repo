What this tool can — and cannot — confirm

Canvas re-export commonly removes EXIF and embedded file metadata, including many C2PA metadata records. Pixel-embedded SynthID is different: it can survive resizing, compression and changes that are invisible to people. This tool runs a subtle pixel-signal experiment and provides image-quality comparisons. We do not claim it always removes SynthID, fools platforms, or makes AI images appear authentic. If you need reliable verification, check both the original and result with an official detector.

Does this actually detect a SynthID watermark?

No. We do not have a verified SynthID detector integrated into this website. A file's appearance and PSNR cannot show whether SynthID is present. You can check at synthid.com.

Will my image look exactly the same?

The image keeps the same dimensions and should look very close at normal zoom, especially in Gentle mode. Pixel values change, so the result is not pixel-identical. Stronger modes may slightly affect fine details; use the comparison slider to review.

Does this remove C2PA and EXIF metadata?

Re-exporting through browser Canvas removes most original file metadata. We do not separately validate every type of embedded credential. If metadata is important to your workflow, inspect the downloaded file with a trusted metadata tool.
